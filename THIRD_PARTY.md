# Third-party software

The project uses third-party open-source packages declared in `backend/requirements.txt` and `frontend/package.json`. Their licenses remain with their respective authors. Review each package's license and applicable attribution terms before distribution.

The official Crunch Week starter pack is included in this repository, including its validator, dataset, and examples. Preserve the starter pack's terms and attribution requirements supplied by the organizers.

The frontend uses React, React Router, Vite, TypeScript, and Lucide icons. The backend uses FastAPI, SQLAlchemy, Alembic, Pydantic, Psycopg, and Google OR-Tools as listed in their respective dependency manifests. No paid API service is required. The natural-language assistant in this project is implemented with local deterministic parsing; it does not send request text to an external LLM provider.
